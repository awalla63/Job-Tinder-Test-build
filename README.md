# Job-Tinder-Test-build
Initial test build of tinder-like job search web application 

- This project intends to create a web application that will treat the job searching as a tinder like experience. Job seekers will be matched to jobs based on their resume and initial survey questions. Employers will also be able to swipe on candidates based on resume and initial survey questions. There should be matching based on resume and job description as well as survey questions. The recommendation system should be based on these matches. Candidates and employers should be able to like each other. Once there is a mutual like, there should be a link to apply. Finding real users may be difficult. especially on the employer side, but just want to focus on getting the application working.
